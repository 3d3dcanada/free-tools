# Security

The tools run in the visitor's browser and have no server component, so the usual report is a way for a
crafted file, a saved draft or an imported project to run script, read another file or send data
somewhere. Those are treated as the most serious kind.

To report one, email **info@3d3d.ca** with the steps to reproduce and, if you can, a file that shows
it. Please do not open a public issue for a vulnerability until it is fixed. You will get a reply
confirming receipt; fixes are published in the repository and noted in the commit message.

Out of scope: the 3D3D website itself (report that to the same address, separately), and issues that
need a victim to install a malicious browser extension.
